## 1. 文档说明

### 1.1 编写目的

织蝶云官方文档为单页静态文档（所有"子链接"均为同一页面内的锚点章节），内容以功能界面截图配简述为主。本文档将其重新组织为需求文档形式：正文功能点来自官方文字说明，各模块下新增 **"界面要素（截图识别）"** 小节，内容来自对官方截图（`https://doc.zhidieyun.com/oa/img/oa/*.png`，共 44 张）的逐一识别，供后续设计、开发与验收参考。

### 1.2 术语与角色

| 术语 | 说明 |
|------|------|
| 申请 / 流程 | 用户在审批模块中发起的一次审批事务 |
| 节点 | 审批流程中的一个处理环节（发起人 / 审批人 / 抄送人 / 条件分支） |
| 流转 | 上一个节点处理完成后，流程自动进入下一个节点 |
| 转交 | 未处理的审批单转给其他人员代为审批 |
| 催办 / 催审 | 申请人提醒当前审批人尽快处理 |
| 控件库 / 套件库 | 审批表单设计器中的基础控件与人事行政套件 |
| 权组 | 系统模块中的权限分组，权限控制的基本单位 |
| 屏蔽 | 职级 / 职称的停用操作（屏蔽后进入"屏蔽职级/职称"视图） |

## 2. 审批模块（approval）

> 来源：https://doc.zhidieyun.com/oa/index.html#js-approval
> 截图：approval-myapply / approval-unprocess / approval-processed / approval-cc / approval-detail / approval-change / approval-detail2 / approval-apply / approval-module / approval-module-my / approval-module-cc

### 2.1 模块概述

审批主页按"与我相关"的四个维度组织审批流程的列表展示：**我的申请、待我审批、我已审批、抄送给我的**（顶部 Tab 带实时计数）。每个审批类型下有单独的列表展示：`我的XX`、`我的审批`、`抄送给我的`。

### 2.2 功能需求清单

| 编号 | 功能点 | 子锚点 | 优先级建议 |
|------|--------|--------|-----------|
| AP-01 | 我的申请 | #js-approval-manage | P0 |
| AP-02 | 待我审批 | #js-approval-unprocess | P0 |
| AP-03 | 我已审批 | #js-approval-processed | P0 |
| AP-04 | 抄送给我 | #js-approval-cc | P0 |
| AP-05 | 审批详情 | #js-approval-detail | P0 |
| AP-06 | 创建申请 | #js-approval-apply | P0 |
| AP-07 | 具体审批模块视图 | #js-approval-module | P1 |

### 2.3 功能点详述

#### AP-01 我的申请
- **功能描述**：汇总当前用户发起的全部审批流程。
- **行内操作**：针对每条申请支持 `编辑`、`删除`、`催审`、`撤回`。
- **验收要点**：操作仅对流程状态允许的情况下生效（如已结束的流程不应可撤回，此为合理推导，原文未明示）。

#### AP-02 待我审批
- **功能描述**：汇总当前用户待处理的审批流程。
- **业务规则**：上一个用户审批后，流程会自动流转到下一个节点。

#### AP-03 我已审批
- **功能描述**：汇总当前用户已经审批过的流程。

#### AP-04 抄送给我
- **功能描述**：汇总抄送给当前用户的流程。

#### AP-05 审批详情
- **入口**：审批列表中点击审批名称进入。
- **功能描述**：
  - 详情页内容展示依据**流程设置**动态渲染：部分选项可编辑、可隐藏，不同节点显示不同的信息（依赖审批设置模块的流程配置正确完成后才能正确显示）。
  - **未处理状态**：支持将审批**转交**给其他人员进行审批。
  - 页面左侧展示当前审批的**进度与状况**（审批进度时间轴）。
  - **已处理状态**：提供对应的已处理视图。

#### AP-06 创建申请
- **入口**：审批列表右上侧导航，点击 `创建新申请`。

#### AP-07 具体审批模块视图
- **功能描述**：审批详情页顶部提供三个切换按钮：`我的XX`、`我的审批`、`抄送给我的`，用于查看具体审批类型模块的相关信息。

### 2.4 界面要素（截图识别）

#### 2.4.1 审批列表页（四个 Tab 通用布局）

- **顶部主导航**（居中，带实时计数）：`我的申请(n)` / `待我审批(n)` / `我已审批(n)` / `抄送给我(n)`；当前 Tab 高亮（绿色底）。
- **右上角**：消息通知图标（红色角标计数）、用户头像 + 用户名下拉菜单。
- **状态筛选 Tab**（随所在主 Tab 变化）：
  - 我的申请：`全部` / `审批中` / `同意` / `拒绝` / `驳回` / `撤回` / `草稿`
  - 我已审批：`全部` / `同意` / `拒绝` / `驳回`
  - 抄送给我：`全部` / `审批中` / `同意` / `拒绝` / `驳回`
- **右侧工具条**：`+ 创建新申请`（红色主按钮）、`选择审批类型 ▾` 下拉、名称搜索框、`筛选` 按钮、`审批流程管理` 按钮（跳转审批设置模块）。
- **列表项**：类型标签（如"考勤"，绿色描边）– 审批名称（如"请假"）；摘要（如"请假类型:事假 请假时长:2.00"）；状态标签（`审批中` 紫色 / `同意` 绿色）；申请时间或审批时间（如 06–22 14:05）。
  - 我的申请列表行尾有行内操作：`催办`（黄色）、`撤回`（灰色）。
- 列表底部显示 `共N条`。

#### 2.4.2 审批详情页（未处理，截图 approval-detail）

- **面包屑**：`请假`（当前审批类型名）；顶部仍有模块切换：`我的请假` / `我的审批` / `抄送给我`。
- **右上操作**：`审批日志`、`返 回`。
- **表单区**（左侧主区）：
  - 标题（如"请假"）+ `打印` 按钮；副标题 `By 发起人名 创建时间`。
  - 字段表格：姓名 / 部门 / 职位；申请编号（如 `2021062214050101`，绿色标签样式）；创建日期；请假类型（事假）；起止时间（如 2021-06-22 16:00 至 2021-06-22 18:00）；请假时长（2.00 时）；请假事由；附件（`下载/预览` 按钮）。
- **审批进度时间轴**（右侧）：按节点自上而下展示——节点角色标签（发起 / 依次节点）→ 处理人卡片（头像 + 姓名 + 职位 + 部门，如"美丽 人事经理 人事部"）+ 状态标签（`审批中`）；下一节点同样展示（如"张工 市场经理 市场部"）。
- **审批操作区**（表单区下方"审批"标题内）：
  - `选择常用审批意见` 下拉框（含"批准，尽快处理"等预置短语，选中后自动填充意见框）；
  - 审批意见多行文本框；
  - 操作按钮：`同意`（绿）/ `拒绝`（红）/ `驳回`（橙）/ `转交`（灰，位于右侧）。

#### 2.4.3 转交弹窗（截图 approval-change）

- 弹窗标题：`转交他人`。
- 字段：`* 转交给`（人员选择，如"李行"）、`转交原因`（多行文本，如"外出，麻烦你去面试一下！"）。
- 按钮：`关 闭` / `提交保存`。

#### 2.4.4 审批详情页（已处理，截图 approval-detail2）

- 时间轴中已处理节点展示：处理人 + 审批时间 + 审批意见（"批准，尽快处理。"）+ `同意` 结果标签。
- 审批操作区替换为提示条：`✓ 您已经审批，无需再进行审批操作！`。

#### 2.4.5 创建新申请页（截图 approval-apply）

- 按审批类型分类分组展示**审批类型卡片**（图标 + 名称 + 描述），共 4 组 15 类：

| 分组 | 审批类型（描述） |
|------|------------------|
| 人事 | 转正（用于试用期内员工）、招聘（用于人员需求申请）、离职（适用于离职审批） |
| 考勤 | 请假（适用于请假申请）、出差（适用于出差申请）、加班（适用于加班申请）、外出（适用于外出申请）、补卡（适用于补卡申请） |
| 行政 | 采购（用于企业办公所需材料）、用章（用于公司印章使用）、用车（适用于因公使用车辆） |
| 财务 | 报销（适用于公司报销审批）、付款（适用于付款申请）、合同（适用于审批合同）、预支（适用于预支申请） |

#### 2.4.6 具体审批模块视图（截图 approval-module / -my / -cc）

- 进入某一审批类型（如"请假"）后，顶部三个 Tab：`我的请假` / `我的审批` / `抄送给我`。
- 我的请假：状态筛选 全部/审批中/同意/拒绝/驳回/撤回/草稿；右上 `+ 创建请假` + 名称搜索 + 筛选；列表项带类型标签 + `同意` 状态标签 + 申请时间。
- 我的审批：子筛选 Tab `全部请假` / `待审批请假` / `已审核请假`；空态提示"暂无审批流程"。
- 抄送给我：状态筛选 全部/审批中/同意/拒绝/驳回；空态提示"暂无审批流程"。
- 按钮文案随审批类型变化（请假类型下为"创建请假"）。

## 3. 审批设置模块（approval set）

> 来源：https://doc.zhidieyun.com/oa/index.html#js-approvalset
> 截图：formbuilder / formbuilder-add / formbuilder-edit / formbuilder-design×3 / formbuilder-flow×7 / formbuilder-preview / formbuilder-permission / formbuilder-type

### 3.1 模块概述

面向管理员的审批流程配置模块。入口：在我的申请审批列表右上角点击 `审批设置`（截图中列表页按钮为 `审批流程管理`）进入。顶部两个 Tab：`审批设置` / `类型设置`。在审批管理中可创建新审批、停用/启用审批、对审批各项进行配置。

### 3.2 功能需求清单

| 编号 | 功能点 | 子锚点 | 优先级建议 |
|------|--------|--------|-----------|
| AS-01 | 审批管理 | #js-approvalset-manage | P0 |
| AS-02 | 创建新审批 | #js-approvalset-create | P0 |
| AS-03 | 编辑审批 | #js-approvalset-edit | P0 |
| AS-04 | 审批表单（表单设计器） | #js-approvalset-form | P0 |
| AS-05 | 流程设置（流程设计器） | #js-approvalset-flow | P0 |
| AS-06 | 审批预览 | #js-approvalset-preview | P1 |
| AS-07 | 审批权限 | #js-approvalset-permission | P0 |
| AS-08 | 审批类型 | #js-approvalset-sort | P1 |

### 3.3 功能点详述

#### AS-01 审批管理
- **入口**：我的申请审批列表 → 右上角 `审批设置`。
- **功能描述**：审批管理列表，支持创建新审批、停用或启用审批、对审批各项进行处理。

#### AS-02 创建新审批
- **入口**：审批管理列表右上角 `创建新审批`。

#### AS-03 编辑审批
- **入口**：审批管理列表 → 列表行点击 `编辑`。

#### AS-04 审批表单
- **入口**：审批管理列表 → 列表行点击 `表单`。
- **功能描述**：表单设计器内置大量组件，分为三类：
  - **控件库**：基础控件库；
  - **套件库**：相关人事套件库；
  - **关联审批**：已发布的审批，可被关联引用。

#### AS-05 流程设置
- **入口**：审批管理列表 → 列表行点击 `流程`，跳转到流程独立页进行**大屏（可视化拖拽）设计**。
- **节点类型**：包括 `发起人`、`审批人`、`抄送人`、`条件` 四项。
- **业务规则**：
  - 每个节点都可以设置条件；
  - 各个节点都可以单独设置相关选项；
  - ⚠️ **关键规则（原文强调）**："流程表单"或"审批流程"设计好后，**一定要点"发布"按钮**，否则配置不生效。

#### AS-06 审批预览
- **入口**：审批管理列表 → 列表行点击 `预览`。

#### AS-07 审批权限
- **入口**：审批管理列表 → 列表行点击 `权限`。

#### AS-08 审批类型
- **入口**：审批管理顶部导航 `类型设置`。
- **功能描述**：可根据实际情况对审批类型进行创建、编辑、删除等操作。

### 3.4 界面要素（截图识别）

#### 3.4.1 审批管理列表（截图 formbuilder）

- 顶部 Tab：`审批设置`（高亮）/ `类型设置`；右上：`+ 创建新审批`（红）、状态下拉、标题/标签搜索框、`筛选`、`返 回`。
- 预置 15 个系统审批，每行：图标 + 名称 + 描述、所属分类、"审批 - 系统" 来源标识、两个状态标签（`已发布` / `已启用`）、操作按钮组：`编辑` / `表单` / `流程` / `预览` / `权限` / `停用`（红）。

| 分类 | 预置审批 |
|------|----------|
| 考勤 | 请假、出差、加班、外出、补卡 |
| 财务 | 报销、付款、合同、预支 |
| 行政 | 采购、用章、用车 |
| 人事 | 转正、招聘、离职 |

#### 3.4.2 创建新审批表单（截图 formbuilder-add）

- 字段：`* 类型`（选择审批类型下拉）、`* 审批名称`（提示：最多 2–10 汉字，如：合同、请假）、`图标`（图标选择器）、`描述`（多行，如"用于出差申请"）。
- 按钮：`提交保存`。

#### 3.4.3 编辑审批 —— 五步配置导航（截图 formbuilder-edit）

- 顶部五步 Tab：`命名审批` → `表单设计` → `流程设置` → `预览审批` → `权限设置`（当前步高亮）。
- 命名审批步内容与创建表单一致（类型/名称/图标/描述），如"请假·审批设置"。

#### 3.4.4 表单设计器（截图 formbuilder-design / -design2 / -design3）

- 三栏布局：左侧组件面板（三个 Tab：`控件库` / `套件库` / `关联审批`）、中间表单画布、右侧属性面板。
- **顶部红色提示条**：`所有插入的控件须保存。审批表单设计好后，请在"流程设置"下点击"发布"`。
- **控件库**（21 个基础控件）：单行输入框、多行输入框、富文本输入框、单选框、多选框、下拉框、图片、附件、日期、时间、日期区间、日期时间、联系人、部门、金额、数字、电话、身份证、省市（每个控件带类型小图标）。
- **套件库**（分组"人事行政套件"，5 个套件）：请假套件、出差套件、时长套件、报销套件、物品套件。
- **关联审批**：以卡片网格列出全部 15 个已发布审批（请假/报销/出差/采购/加班/外出/用章/付款/用车/合同/转正/招聘/离职/补卡/预支），可点击关联插入表单。
- **画布示例**（请假表单默认模板）：
  - `* 请假类型`（下拉）
  - `* 起止时间`（开始日期 至 结束日期，区间选择）
  - `时长(天)`（红色"(天)"后缀标识）
  - `* 请假事由`（多行文本）
  - `附件`（`上传文件` 按钮）
- **右侧属性面板**（标题随选中控件变化，如"请假套件属性"）：
  - 勾选项：`必填`、`在列表中显示`（带帮助图标）
  - 按钮：`保 存` / `移 除`

#### 3.4.5 流程设计大屏（截图 formbuilder-flow / -flow1~5 / -flow33）

- **画布**：独立全屏页，标题为审批名（如"请假审批"）；右上 `返 回` / `发布`（红色主按钮）；右下缩放控件（− / 100% / +）。
- **默认流程**（新审批初始态）：

  ```
  [发起人: 所有人] →(+)→ [审批人: 发起人自选] →(+)→ [抄送人: 发起人自选] →(+)→ 流程结束
  ```

  - 发起人节点为深蓝、审批人为橙色、抄送人为青绿色；节点间 `+` 按钮用于插入节点或**添加条件**分支。
- **发起人面板**（点击发起人节点，截图 flow / flow1）：
  - Tab1 `设置发起人`：已选范围展示（如"技术部,市场部,运营部,行政部"，部门多选），按钮 `添加/修改发起人`；不设置时默认"所有人"。
  - Tab2 `表单操作权限`：对表单每个字段（请假类型 / 起止时间 / 请假时长 / 请假事由 / 附件）逐字段设置单选：`可编辑` / `只读` / `隐藏`（发起人节点默认全部"可编辑"）。
- **审批人面板**（截图 flow3 / flow33）：
  - Tab1 `审批人设置`：
    - 审批人单选：`指定成员` / `主管` / `部门` / `发起人自选` / `发起人自己`

## 8. 关键业务规则汇总

1. **审批自动流转**：上一用户审批完成后，流程自动流转至下一节点（AP-02 / AP-04）。
2. **流程必须发布**：流程表单或审批流程设计完成后，必须点击"发布"按钮方可生效（AS-05；表单设计器顶部亦有红色提示条，见 3.4.4）。
3. **详情页动态渲染**：审批详情页依据流程设置展示——字段可编辑、可隐藏、不同节点显示不同信息；未发布配置前无法正确显示（AP-05 ↔ AS-05）。
4. **转交**：未处理的审批支持转交其他人员审批，需填写转交人与转交原因（AP-05，见 2.4.3）。
5. **审批结果四态**：同意 / 拒绝 / 驳回 / 转交；列表按审批中/同意/拒绝/驳回/撤回/草稿筛选（2.4.1、2.4.2）。
6. **字段级节点权限**：流程中每个节点（发起人/审批人）可对每个表单字段独立设置 可编辑/只读/隐藏（3.4.5）。
7. **审批人五种指定方式**：指定成员 / 主管 / 部门 / 发起人自选 / 发起人自己；支持选一人或多人，范围限全公司或指定成员（3.4.5）。
8. **条件分支带优先级**：条件分支可设优先级（优先级1、2…），条件字段支持时长比较运算与请假类型多选（3.4.5）。
9. **假期限额粒度**：假期类型支持限额（是/否）与时长单位（天 / 小时 / 半天），并有"权重"字段用于排序（HD-01、5.3.5）。
10. **假期余额三账本**：每员工每假期类型记录 假期时长 / 已用时长 / 剩余时长，支持"不限额"，并有余额日志（可回溯关联审批流程）（5.3.2 / 5.3.3）。
11. **考勤打卡频次**：默认每天打卡 2 次，考勤时间三要素：上班时间 / 下班时间 / 加班时间；打卡记录记录 IP（4.3.1 / 4.3.3）。
12. **审批可关联**：已发布的审批可在其他审批表单中被关联引用（AS-04，见 3.4.4）。
13. **员工软删除**：员工删除进入回收站可恢复；职级/职称使用"屏蔽"作为停用手段（SY-01、6.3.3 / 6.3.4）。
14. **权限模型**：功能权限按"权组"配置，覆盖主页/审批/日程/报告/知识/文档/相册/公告/邮件/系统十个分组（6.3.6）。

## 9. 非功能要求（由文档推断的补充建议）

> 以下为整理时的补充建议，非官方文档原文。

- **权限体系**：系统模块的"权组"应作为全局权限基础，审批设置（AS-01/AS-07）与考勤设置（CK-03）、假期类型管理（HD-04）等管理入口需受权限控制。
- **操作留痕**：审批的催办、撤回、转交等操作建议记录操作日志；系统模块已明确要求提供登录日志（SY-06，含浏览器/OS/IP/状态）。
- **软删除**：员工删除采用回收站模式，其他实体（审批类型、假期类型等）建议采用一致的软删除策略。
- **考勤统计口径**：我的考勤与全部考勤均提供"当月小计"（出勤天数、迟到次数）与打印、导出能力，需保证统计口径一致。
